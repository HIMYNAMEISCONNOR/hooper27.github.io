## Modes & rules

- 1v1, 2v2, 3v3, 4v4, **5v5**
- Blacktop scoring (1s & 2s) or NBA (2s & 3s)
- Target score 11/15/21/30, make-it-take-it, win-by-2, optional timed game with sudden-death OT
- Rookie / Pro / All-Star CPU, shot meter on/off, sound on/off

## Controls

| Key | Action |
|---|---|
| WASD / Arrows | Move |
| Shift | Turbo (drains stamina) |
| Space (hold + release) | Shoot — release in the **green window** for an automatic make |
| Space while driving | Dunk / layup |
| Space on defense | Jump to contest / block |
| E | Pass (with ball) / steal (on defense) |
| Q | Crossover — break ankles |
| P / Esc | Pause |

## Tips

- Hit **3 shots in a row** and you're **ON FIRE** until you miss.
- Contested shots almost never go in — use the crossover (Q) or a pass to get separation.
- Shaq and Kareem grab every rebound; get out and run past them.
- Curry's green window from deep is huge. Hunt 3s with him.
